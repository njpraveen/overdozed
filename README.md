# Overdozed

A demo T-shirt storefront that mixes traditional Hindu temple art with neon, futuristic effects.

## Features

- Om "ignite" intro, rotating golden mandala, floating diya particles and a chakra cursor trail
- Wireframe gopuram hero with mouse parallax and a 3D rotating T-shirt
- Gods Series (Shiva, Ganesha, Hanuman, Krishna, Durga, Vishnu) that filters the shop
- Product grid with 3D tilt, holographic shimmer, colour and size pickers
- Filters (god, colour, size, price), sorting and live search
- Quick-view modal with zoom, quantity and size chart
- Cart drawer saved in localStorage, with free-shipping progress
- Temple Day Mode, radial mobile menu, reviews carousel, newsletter signup

## Run it

It's a single self-contained file. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Notes

This is a demo: checkout and the newsletter form don't send data anywhere, and the reviews are sample content.
